# run guide

# Prerequisites
- Git 2.23 or later
- JDK 17 or later
- Python 3.9 or later
- The `java`, `javac`, and `python3` commands must be available on `PATH`.

# Run the demo

python3 run.py demo

The demo compiles and runs the library application. It demonstrates the catalog, borrowing and returning books, overdue fees, and receipt generation.
